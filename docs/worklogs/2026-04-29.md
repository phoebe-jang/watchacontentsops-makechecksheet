## 4. 처리 룰 (현재 확정 사양)

`converter.py` 안에서 `_classify(row)`, `_display_day(row, prev_normal_day)` 등으로 구현. 룰들이 누적·수정되어왔으니 **이 절이 진실 소스(source of truth)**임.

### 4.1 입력
- 편성표 CSV (한국어 헤더). 매주 동일한 컬럼 구조.
- 컬럼 (20개, 순서 고정):
  ```
  비고 / 예약작 / 오픈일 / 요일 / 시간 / Tier / id / code / Title /
  지난주 e/n / 지난주 f/n / 이번주 e/n / 이번주 f/n /
  오픈 에피 수 / 편성비고 / WX/동시방영 / 최종회차 / CP bill / 원본경로 / 창고
  ```

### 4.2 출력
- 검수시트 70컬럼 .xlsx. 헤더 행은 포함하지 않음(사용자가 자기 시트 위에 붙여넣음).
- 폰트: **Arial 10pt** (헤더/종영/알림 행은 Bold)
- 컬럼 인덱스 매핑 (`converter.py`의 `COL_*` 상수):
  - `COL_A=0` (구분/요일/연휴지연 비고), `COL_TIER=1`, `COL_NEW_SUMMARY=2` (=원본검수, 신규 요약 위치),
  - `COL_SEASON_ID=9`, `COL_SEASON_CODE=10`, `COL_SEASON_TITLE=11`, `COL_MAPPING_TYPE=12`,
  - `COL_EPISODE_NUMBER=15`, `COL_FORMAL_NUMBER=16`, `COL_CP=18`, `COL_FILE_PATH=45`

### 4.3 행 분류 (`_classify`)
```
편성비고 그대로의 부분 매칭은 절대 X. 정확한 컬럼 값 매칭으로만 분류.
```
- `cancelled` (결방/홀드백): **`이번주 e/n` 컬럼 값이 정확히 `결방`/`홀드백`**일 때만. (편성비고 부분매칭 제거 — "이전 결방 후 재편성" 같은 텍스트로 인한 오인식 방지)
- `new` (신규작): `편성비고`에 `신규` 포함
- `prev_day` (전날 셋팅): `비고`(A열)에 `전날 셋팅` 포함
- `reserved` (예약작): `시간`이 `18:00`이 아닌 행
- `normal`: 위 어느 것도 아닌 행

### 4.4 표시 요일 (`_display_day`)
- **`연휴지연` 비고**: 편성표 csv 위치상 직전 일반 요일에 따라감 (예: 화요일 행 다음에 적힌 행 → 화요일 검수시트로)
- **`전날 셋팅`**: 강제로 전날 (`DAY_PREV` 매핑)
- **예약작 + 시간 < 12시**: 전날
- **토/일 행**: 자동으로 **금요일**에 합쳐짐 (검수시트는 월~금만 만들어짐)
- **`요일`/`시간` 컬럼이 `비정기`**: 검수시트에서 제외

### 4.5 회차 분할
- `이번주 e/n`이 `X-Y` 범위 형태이면 X, X+1, ..., Y로 한 행을 여러 행으로 분할
- `이번주 f/n`도 짝지어 같이 분할 (`a-b` 형태 → 동일 개수, 비어있으면 모두 빈칸)
- 분할된 각 행에 같은 Title/CP/원본경로 복제

### 4.6 mapping_type (자막/더빙)
- `Title` 끝이 ` - 자막` → `mapping_type` 컬럼에 `basic` + Title에서 꼬리 제거
- ` - 더빙` → `dubbing`

### 4.7 출력 순서 (요일별)
```
[요일 헤더 행]
편성표 csv 순서 그대로 (예약·일반 섞여 있음)
전날 셋팅 (prev_day, 결방 직전)
결방/홀드백 (cancelled)
연휴지연 그룹 (holiday_block: 헤더 1행 + 콘텐츠 N행, 비고 텍스트별로 묶임)
[금요일이면 EBS 시작행 + EBS 콘텐츠]
```
**중요**: 사용자가 이전에 "예약작을 시간순 정렬"한 코드를 보고 "정렬하지 마라, csv 순서 유지"라고 명시적 정정. 따라서 reserved도 별도 정렬 X, csv 순서 그대로.

### 4.8 요일 헤더 행
- A열: `월요일`, `화요일`, ...
- C열(=`원본검수`): 신규 요약 한 줄 (`신규: 타이틀 N화 (CP) / ...`)
- 신규작은 별도 섹션이 아니라 **그 요일 헤더 행의 C열에 합쳐서** 표기
- CP는 꼬리 코드 제거: `WAG-RS50` → `WAG`, `BELLMEDIA-FLAT` → `BELLMEDIA` (정규식 `-[A-Z0-9]+$`)

### 4.9 휴일 요일 자동 판정
- 비고에 `(기존 X에피)` 패턴이 있고 + X 요일에 해당하는 날짜가 **`KR_HOLIDAYS_2026`** set에 있을 때만 휴일 인정
- `KR_HOLIDAYS_2026`는 2026년 한국 공휴일 하드코딩. 다른 해엔 갱신 필요.
- 휴일 요일 헤더: 형광 초록 `#00FF00`, A열 텍스트 `(요일 M/D 휴일)`
- 휴일 요일의 일반 콘텐츠/결방은 음영 X (no_fill=True). 단 **연휴지연 그룹은 자체 음영 유지** (no_fill 미적용 — 사용자가 명시한 룰)

### 4.10 종영
- `편성비고`에 `종영` 포함된 행 → 분할 후 마지막 회차의 A열에 `종영` 텍스트
- 다른 분할 행에는 표시 X

### 4.11 종영 의심 알림 (`check_jongyeong_alerts`)
- `최종회차` 컬럼의 가장 큰 숫자보다 `이번주 e/n`의 가장 큰 숫자가 더 클 때
- 단, 편성비고에 이미 `종영` 적힌 행은 제외
- 시트 맨 위에 노란 행으로 메시지 추가: `확인 필요 [Title] N회차를 끝으로 종영인 것으로 확인됨`
- 미리보기에도 빨간 좌측 보더 콜아웃 박스로 표시
- 해당 행 자체도 **행 전체 옅은 파랑(#CFE2F3)**으로 시각 강조

### 4.12 금요일 EBS 별도 섹션
- 식별: `CP bill`이 `EBS`로 시작 + `요일`이 빈칸 (편성표 맨 아래 EBS 그룹)
- 금요일 검수시트 하단에 `EBS` 시작행(회색 #D9D9D9) + 콘텐츠 행들(흰색 무음영)
- 콘텐츠 행 컬럼: `원본경로`/`이번주 e/n`/`이번주 f/n` 빈칸 / A열에 편성비고 텍스트

### 4.13 월요일 + 전날 셋팅 = 제외
- 편성표 한 주는 월~금 단위. 월요일에 적힌 `전날 셋팅` 행은 **전주 금요일에 이미 들어간 것으로 간주**하고 이번 주 검수시트에서 자동 제외.

### 4.14 색상 매핑 (검수시트 템플릿 시트2 가이드 기준)

| 케이스 | hex | 비고 |
|---|---|---|
| 요일 헤더 / EBS 시작행 / 연휴지연 헤더 | `#D9D9D9` | 연한회색 1 |
| 휴일 요일 헤더 | `#00FF00` | 녹색 (형광 초록) |
| 예약작 / 전날 셋팅 | `#EAD1DC` | 연한자홍색 3 |
| 결방/홀드백 | `#E6B8AF` | 연한붉은딸기색 3 (←옅은 핑크-적색) |
| 연휴지연 콘텐츠 | `#B7B7B7` | 회색 (한 단계 진하게) |
| 종영 의심 행 (행 전체) | `#CFE2F3` | 옅은 파랑 |
| 종영 셀 노란 배지 | `#FFF292` | **미리보기에만 표시, xlsx에는 음영 X** |

### 4.15 미리보기 그리드 고정
- HTML 표 + `table-layout: fixed` + `<colgroup>`로 컬럼 폭 고정
- A열은 폭 96px + `overflow: visible` (요일 헤더, 연휴지연 헤더의 긴 텍스트가 옆 빈 셀 위로 흘러나옴 — 구글 시트 셀 오버플로우 동작 흉내)
- 헤더 행 C열(신규 요약)도 colspan으로 옆 셀들 시각적으로 합침
- 다른 셀: `overflow: hidden` + `text-overflow: ellipsis` + `nowrap`

## 9. 작업 중 발견한 함정 / 디자인 결정의 근거

### 9.1 사용자 룰 정정 누적
처리 룰은 첫 정의 후 여러 차례 정정됨. 다음 세션에서 룰 충돌 시 **최신 정정이 진실**:
- 회차 분할: 처음 추가 → 사용자가 "넣지 마" → 다시 "원래대로" → **현재: 분할 O**
- 예약작 정렬: 처음 시간순 sort → 사용자가 "csv 순서 유지" → **현재: 정렬 X**
- 신규작: 처음 별도 섹션 → 사용자가 "요일 헤더 C열에" → **현재: 헤더 C열 합산**
- 연휴지연: 처음 두 줄 → 한 줄 → 다시 두 줄 → **현재: 그룹 헤더 + 콘텐츠 두 톤 회색**
- 결방 식별: 편성비고 부분 매칭 → 사용자가 "오인식 발견" → **현재: `이번주 e/n` 정확 매칭만**
- prev_day 음영: 살구색 → 사용자가 "예약작과 같은 핑크" → **현재: `#EAD1DC` 핑크 + A열 `X 에피` 표기**
- 종영 셀: xlsx에도 노란 음영 → 사용자가 "다운로드엔 음영 X" → **현재: 미리보기만 노란 배지**
- 종영 의심: 회차 셀만 파란색 → 사용자가 "행 전체 파란" → **현재: 행 전체 옅은 파랑 fill, 셀 폰트 강조 X**

### 9.2 Streamlit 자동 rerun 함정
`st.download_button` 클릭은 자동 rerun. 단발성 `if run:` 블록에 처리 결과를 두면 사라짐. **반드시 `st.session_state`에 캐시**해서 다시 그릴 것.

### 9.3 TOML secrets 타입 함정
`app_password = 112334556` (따옴표 없음) → int. text_input은 str. `==` 비교 항상 False. 양쪽 `str()`로 정규화하는 게 안전.

### 9.4 Streamlit container 디자인 한계
- `st.container(border=True)`의 wrapper 클래스를 직접 변경 불가
- 모든 container에 동일 스타일 적용되거나, container 안 모든 위젯에 동일 스타일 적용됨
- specific 카드만 타겟하려면 별도 markdown 클래스 + container 내부 `<div class="...">` 트릭 (다만 위젯 nesting은 안 됨)

### 9.5 HTML 표에 colspan + table-layout: fixed
- 컬럼 폭 고정하려면 `<colgroup>` + `table-layout: fixed`
- 특정 셀만 옆 셀 위로 흘러나오게 하려면:
  - colspan으로 합쳐서 한 셀이 여러 컬럼 차지 (헤더 행 C열 신규 요약 처리 방식)
  - 또는 폭은 고정한 채 `overflow: visible + nowrap` (A열 처리 방식)
